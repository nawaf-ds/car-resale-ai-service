# Used-Car Listing Price Assessment

An SDA-AIE-113 capstone service that estimates a used vehicle's listing value and applies explicit policy bands to classify a seller's asking price as `BELOW_RANGE`, `WITHIN_RANGE`, or `ABOVE_RANGE`.

The project is being implemented in verified stages. The asking price is policy input only and is never a model feature.

See `REQUIREMENTS.md` for acceptance-criteria traceability and current verification status.
